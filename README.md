# Trabalho_OTM
Repositório destinado para o trabalho da disciplina de Otimização do curso de Engenharia da Computação e Informação da UFRJ

## Apresentação

Edite `apresentacao_draft.md` e gere o PowerPoint com:

```powershell
pandoc apresentacao_draft.md -t pptx -o output/apresentacao_draft.pptx
```

O arquivo usa apenas Markdown padrão, exceto pelas fórmulas matemáticas entre `$` ou `$$`. O PowerPoint permite exportar o arquivo gerado para PDF, se necessário.
